A [make.fun](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) entry for **Roast Your Own Agent**: one line roasting the AI agent your own team built.

`main.ts` (Node 22, deterministic, no network) writes a single line of plain
text — at most 140 characters — to `/output/entry.txt`. A judge model compares
the lines two at a time and the funniest takes the biggest share of the $2 reward.

## Run

```sh
node main.ts
cat /output/entry.txt
```
